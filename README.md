# Честная Игра

Интерактивная спортивная драма о выборе между честью и победой.

## Музыкальное сопровождение

Игра использует три типа музыки:

### 🎵 Спокойная музыка (calm-music)
- Играет в обычных сценах и главном меню
- Источники: Kevin MacLeod - "Carefree", "Wallpaper"

### 🎺 Эпическая музыка (epic-music)  
- Для важных моментов: выбор тренера, финальный забег
- Источники: Kevin MacLeod - "Heroic Demise", "Drums of the Deep"

### ⚡ Напряженная музыка (tension-music)
- Для драматических сцен: тайные предложения, имплант
- Источники: Kevin MacLeod - "Darkest Child", "Sneaky Snitch"

## Добавление собственной музыки

Чтобы добавить собственные музыкальные треки:

1. Поместите MP3 файлы в папку `audio/`:
   - `audio/calm.mp3` - спокойная музыка
   - `audio/epic.mp3` - эпическая музыка  
   - `audio/tension.mp3` - напряженная музыка

2. Файлы должны быть в формате MP3, желательно с битрейтом 128-192 kbps

3. Рекомендуемая длительность: 2-5 минут (треки зацикливаются автоматически)

## Управление звуком

- 🔊/🔇 - Включить/выключить звук
- Слайдер громкости (0-100%)
- Индикатор текущего типа музыки

## Запуск игры

Просто откройте `index.html` в браузере. Музыка начнет играть автоматически после первого взаимодействия с игрой.

## Технические детали

- Использует HTML5 Audio API
- Fallback к программно генерируемым звукам если внешние треки не загрузятся
- Поддержка CORS для внешних источников
- Автоматическое переключение музыки в зависимости от сцены
